# 量小新 · 中国计量大学新生助手（演示原型）

一个面向大一新生的校园问答 H5：**文字提问 → 知识库检索 → 答案带来源 → 答不准转人工**。

对标河南师范大学“师小新”的迎新问答链路，先做一个人能维护的 MVP，不接学校系统、不碰学生个人信息。

> ⚠️ 这不是中国计量大学官方产品。当前是演示版：日期、金额、宿舍分配等标注“待官方确认”的条目，上线前必须替换为学校官方版本，并由学工部/招生办审核。

---

## 30 秒打开

直接双击 `index.html` 即可（无需安装、无需联网）。

- 对话页：`index.html`
- 问答库：`faq.html`（分类、搜索、折叠答案）

如果要测试“接入大模型”的版本：

```bash
# 需要 Node 18+
set LLM_API_KEY=你的key
set LLM_BASE_URL=https://api.openai.com/v1
set LLM_MODEL=gpt-4o-mini
node server.mjs
# 对话页 http://127.0.0.1:8787
# 问答库 http://127.0.0.1:8787/faq.html
```

然后取消 `index.html` 里这一行的注释：

```html
<script>window.LXX_LLM_ENABLED = true;</script>
```

不配置 key 也能用，前端会自动回退到本地知识库。

## 已实现

- **对话页** `index.html`：聊天式问答 + 转人工 + 运营面板
- **问答库** `faq.html`：迎新服务入口 + 时间轴 + 分类 + 搜索 + 折叠答案 + 语音提问
- 语音提问：浏览器 Web Speech API（Chrome/Edge），需允许麦克风；不支持时提示键盘输入
- 服务卡已接：迎新系统（`http://yx.cjlu.edu.cn`）、2026-2027 缴费须知、本科招生网校园地图、绿色通道指南；迎新系统校外访问可能需校园网/VPN
- 91 条迎新知识库，分 8 类：报到、缴费奖助、宿舍生活、校区交通、学习教务、军训体检、安全防骗、家长/心理
- 文字提问 + 浏览器语音输入（Chrome/Edge 支持）
- 中文同义词归一：`啥→什么`、`咋→怎么`、`缴→交`
- 答案卡片：状态标签（官方口径/通用指引/待官方确认）、步骤、来源、更新时间
- “还有问题”追问 chips
- 答不准时给相近问题 + 转人工
- 转人工弹窗：官网、辅导员、宿管、保卫处、心理中心（占位）
- 反馈 👍/👎，存本机
- 运营面板：`index.html?admin=1`，看提问量、命中率、未命中 Top、导出 JSON
- 移动端适配，可直接挂公众号菜单

## 知识库怎么改

打开 `kb.js`，每条结构如下：

```js
{
  id: "report-materials",          // 唯一 id
  category: "报到",                 // 8 类之一
  title: "报到要带什么材料？",       // 答案标题，也会被搜索
  aliases: ["报到材料", "带什么"],   // 同义问法，必须加，否则搜不到
  keywords: ["报到", "材料", "档案"],// 关键词
  status: "general",               // official / general / pending
  answer: "……",                    // 正文，\n 分段
  steps: ["……", "……"],             // 可选，编号步骤
  source: "《新生入学指南》",        // 来源名称
  sourceUrl: "https://www.cjlu.edu.cn/",
  updated: "2026-10-28",
  followups: ["档案怎么转？"]        // 可选，追问 chips
}
```

**三条规则：**

1. `pending` 只放“日期/金额/分配规则”等会变的条目，答案里写清楚“以官方通知为准”。
2. 每条答案必须有一个来源；没有来源的，不要写。
3. 新增问题时，至少写 3 个 `aliases`，用新生真实会说的词，不要用书面语。

改完后刷新页面即可，不需要构建。

## 挂到公众号

### 方案 A：公众号菜单跳 H5（推荐）

1. 把整个目录部署到学校服务器/已备案域名，确保 HTTPS。
2. 公众号后台 → 自定义菜单 → 添加“迎新助手” → 填 H5 链接。
3. 新生点菜单直接打开，无需下载。

> 公众号菜单外链需要公众号有相应权限；没有权限就用方案 B。

### 方案 B：图文 + 二维码

1. 在迎新推文里放 H5 二维码。
2. 新生扫码即用。
3. 适合没有菜单权限、或只想在迎新季临时用。

### 方案 C：迎新系统 banner

在迎新系统首页挂“智能答疑”入口。需要信息中心配合，但流量最精准。

### 方案 D：关键词自动回复（兜底）

公众号自动回复“报到”“宿舍”“缴费”等关键词，返回图文/链接。不是真智能体，但零开发。

## 接入大模型（可选）

`server.mjs` 是一个极简代理：

- 前端把问题和 Top 3 知识库条目发给 `/api/chat`
- 服务端拼 system prompt，调用 OpenAI 兼容接口
- 返回答案，前端渲染成“AI 生成”卡片

环境变量：

| 变量 | 说明 |
|---|---|
| `LLM_API_KEY` | 必填，模型 key |
| `LLM_BASE_URL` | 默认 `https://api.openai.com/v1`，可换 DeepSeek/通义/豆包兼容接口 |
| `LLM_MODEL` | 默认 `gpt-4o-mini` |
| `PORT` | 默认 `8787` |
| `HOST` | 默认 `127.0.0.1`；手机同局域网测试改成 `0.0.0.0` |

**不要把 key 写进前端。** 前端只调 `/api/chat`，key 只在服务端环境变量里。

## 运营：每周只看三件事

1. **未命中 Top 10**：新生问了什么你没覆盖，补 5-10 条。
2. **转人工率**：超过 25%，说明知识库不够或答案太绕。
3. **差评**：点开对应问题，改答案，不要改模型。

面板入口：`index.html?admin=1` → 右上角滑杆图标 → 导出 JSON。

## 合规与边界

- 不收集身份证、准考证、成绩、手机号；日志里的手机号/证件号会自动打码。
- 不接统一身份认证，不做“查我的宿舍/缴费/课表”；这些一律跳学校迎新系统。
- 不承诺“保过/保录/提分”；校园问答不涉及这些。
- 心理危机、诈骗、人身安全：不给诊断，直接转人工/110/120。
- 上线前必须由学工部/招生办审核全部答案；演示版不能直接对外。

## 已知限制

- 语音输入依赖浏览器 `SpeechRecognition`，Safari/部分安卓浏览器不支持。
- 本地检索是关键词 + 二元组匹配，不是语义向量；问法差异大时会漏。
- `?admin=1` 的数据存 `localStorage`，换浏览器/清缓存会丢；正式版应接后端。
- 没有接入学校统一身份认证、迎新系统、VR 地图；这些需要学校配合。
